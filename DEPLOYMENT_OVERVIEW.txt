## 🎯 Deploy in 3 Steps

### 1️⃣ Open Vercel
```
https://vercel.com/new
```

### 2️⃣ Import Repository
- Search: `chiranjeevi200217/dash-gxon-we`
- Click "Import"
- Review settings (should be auto-filled ✓)
- Click "Deploy"

### 3️⃣ Add Environment Variables (After Deploy)
```
Vercel Dashboard → Your Project → Settings → Environment Variables

Add:
- DATABASE_URL (server-only, mark Sensitive)
- JWT_SECRET (server-only, mark Sensitive)  
- NEXT_PUBLIC_API_URL (public)
```
